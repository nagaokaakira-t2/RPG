# [仮題] ドット絵アクションRPG - Phase1 コアプロトタイプ

設計書（design-doc-v2.md）の Phase1 に対応する最小プロトタイプです。

## 実装済み

- Vite + Phaser 3 + TypeScript のプロジェクト構成（設計書1.2のディレクトリ構成に準拠）
- BootScene: プレースホルダーテクスチャの生成（頭・胴・脚の簡易人型シルエット / 丸みのあるモンスターシルエット）
- TitleScene: タイトル画面
- TownScene: トップダウン視点の街（移動・当たり判定のある壁・ギルド受付NPC・フィールドへの出口）
- FieldScene: トップダウン視点のフィールド。敵シンボルが徘徊し、接触するとシンボルエンカウントでBattleSceneへ遷移
- BattleScene: サイドビュー戦闘
  - 左右移動、SPACEジャンプ、Z通常攻撃、SHIFT回避（ジャストタイミングで無敵＋「ジャスト回避！」表示）、Cガード（対応ジョブのみ、被ダメ7割軽減）
  - **必殺技ゲージ（6.2）**：攻撃を当てる/受けるたびに蓄積し、満タンでXキーの必殺技（通常の2.2倍ダメージ）を発動可能
  - **属性相性（6.3）**：火→風→地→水→火の四すくみ＋光と闇の相互弱点。弱点をつくと1.5倍、耐性があると0.5倍のダメージ表示
  - 現在のジョブ/派生ジョブのSTRとエレメントがダメージ計算に反映される
  - HPバー・勝敗判定・元シーンへの復帰。勝利時にJP（熟練度）を獲得
- **ジョブシステム（基本5ジョブ＋1段階目派生）**
  - `jobs.json`：基本5ジョブのステータス・成長率・ガード可否
  - `tier1Jobs.json`：1段階目派生20系統（恒常15＋隠し5）のステータスボーナス・属性
  - 街のギルド受付（Zキーで会話）から、未派生の間は基本ジョブ変更、JP30以上になるとXキーで派生選択画面に切り替えて1段階目の恒常派生を選択可能（4.1の通り一方通行。隠し派生はロック表示のまま選択不可＝未実装のボス素材/レアNPC条件と対応）
- GameState: シーン間共有のシングルトン（ジョブ・派生・JP・属性を保持。Phaser.Events.EventEmitterを継承したイベントバス兼用）

## 動かし方

```bash
npm install
npm run dev
```

### 操作
- 街・フィールド：矢印キー / WASD で移動
- 街のギルド受付NPCに近づいて Z で会話 → ジョブ変更画面（↑↓選択/Z決定/ESC閉じる、JP30以上でXキーにより派生選択画面に切替）
- 戦闘：←→移動 / SPACEジャンプ / Z攻撃 / X必殺技（ゲージ満タン時のみ） / SHIFT回避 / Cガード（対応ジョブのみ）
